# Fonts for the PDF guides

The downloadable guides (`/help/guide/<audience>.pdf`, `lib/help/pdf-document.tsx`) embed the website's own fonts:
Plus Jakarta Sans (400, 600, 700) and Newsreader (500, 600), static TTF files from Google Fonts.
Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows embedding them in documents.
